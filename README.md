# EW Visualizer — Desktop Download

EW Visualizer is a creative visualizer and music-making application for Windows. Explore sound, instruments, visual effects, and composition tools in one desktop app.

## Download and install

1. Open the **Releases** section of this repository.
2. Download the latest `EWVisualizer Desktop Setup` `.exe` file.
3. Run the installer and follow the prompts.
4. Launch EWVisualizer Desktop from your Start menu or desktop shortcut.
5. Enter your license key when prompted.

Electron and Node.js are included in the installed application; you don't need to install them separately.
